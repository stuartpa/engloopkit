# Dead-code proposals

Stage 41 records one high-certainty dead-code candidate at a time.

- Reserve the next three-digit `DEADCODE` number in `../numbering-registry.md` before creation.
- Name records `DEADCODE<NNN>-<brief-kebab-description>.md`.
- Current source must remain unchanged until the user explicitly approves that exact candidate.
- Rejected candidates remain durable with the user's rationale; the next search uses a new number.
- If no candidate passes every certainty check, record `DEADCODE<NNN>-no-certain-candidate.md` and stop.
