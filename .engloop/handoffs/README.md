# ELK handoffs

Stage 50 creates one evidence-backed continuation packet for another chat window or engineering team.

- Reserve the next three-digit `HANDOFF` number in `../numbering-registry.md` before creation.
- Name artifacts `HANDOFF<NNN>-<brief-kebab-description>.md`.
- Scope each handoff to the recent event being transferred; do not summarize the whole project.
- Include recipient, reproduction/completed actions, evidence, current state, constraints, unresolved work, and the receiving party's first recommended action.
- Remove credentials and unnecessary private workload details before cross-team transfer.
